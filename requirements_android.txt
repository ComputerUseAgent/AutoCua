# AutoCua - Android (a real phone on USB: screenshots and UI scans)
# =================================================================
# No pip packages yet. The connector (AutoCua/android_connector/) uses only
# Python's standard library. Packages the Android side needs later go here.
#
# Needed outside pip, fetched or built on first use (from a wheel, nothing
# is built: both Rust agents ship prebuilt). adb is also offered by the setup
# scripts, after a y (python -m AutoCua.android_connector.adb fetch), from
# Google, never from this repo:
#   adb            Google's platform-tools, into AutoCua/android_connector/
#                  platform-tools/ (an adb on PATH wins).
#   autocua-helper.jar
#                  The phone helper (android_connector/Helper.java): takes the
#                  screenshots, as JPEG on the phone, and reads the UI tree.
#                  Built only when Helper.java changes, by
#                  android_connector/build_helper.py, which fetches a JDK,
#                  Android's android.jar and d8 once into
#                  ~/.AutoCua/android-build (about 300 MB). Commit the jar and
#                  nobody else needs Java.
#   Rust + cargo   a checkout builds the Android crate, AutoCua/android, with
#                  them (https://rustup.rs), like the web crate; the pip
#                  wheels ship it prebuilt, so pip users need neither. Its
#                  crates (zune-jpeg, jpeg-encoder, roxmltree, pyo3, ...) are
#                  in AutoCua/android/Cargo.toml; none compiles C or C++,
#                  cargo only links through the system C compiler.
#
#   uv pip install --python .venv/bin/python -r requirements_android.txt
#   # or:  pip install -r requirements_android.txt
